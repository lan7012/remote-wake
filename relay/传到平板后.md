# 安卓平板（Termux）部署步骤

## 1. 解压

把 `relay-tablet-v5.zip` 传到平板的 `Download` 目录，然后在 Termux 里执行：

```bash
cd ~/storage/downloads
unzip relay-tablet-v5.zip -d relay
```

## 2. 写入真实 MAC

把 `config.user.json.example` 复制为 `config.user.json`，并填入你电脑的真实 MAC：

```bash
cd ~/storage/downloads/relay/relay
cp config.user.json.example config.user.json
```

用文本编辑器修改 `config.user.json`：

```json
{
  "token": "REPLACE_WITH_YOUR_OWN_TOKEN",
  "devices": {
    "pc1": "D4:5D:64:AD:0C:6D"
  }
}
```

> MAC 用冒号分隔，不要带短横线。

## 3. 验证链路

```bash
cd ~/storage/downloads/relay/relay
sh verify_termux.sh
```

看到 `/status` 和 `/wake` 都返回 `ok`，且 `targets` 包含 `192.168.xxx.255` 即可。

## 4. 启动中继

验证通过后，保持中继运行：

```bash
sh start_termux.sh
```

## 5. 后台保活

- 打开系统设置 → 电池 → 找到 Termux 和 Tailscale → 关闭电池优化 / 允许后台运行。
- 平板插电即可，不需要强制唤醒锁。
